# Docs Research

Use this skill when implementation depends on current external documentation or a specific source file.

## Steps

1. Prefer official documentation for product behavior.
2. Cache or cite the exact source used for implementation decisions.
3. Distinguish documented behavior from local inference.
4. Update local docs only when the repository behavior is implemented and validated.

## Output

Produce a short source-backed note with the decision, files affected, and validation command.

## Boundaries

Do not add stale citations or claims that the repository does not implement.
