# Base Harness Workbench

Base Harness Workbench는 실행 환경과 AGY 경계를 진단하고, 실행 명령을 미리 보여주며, Run 상태를 관측하는 표준 라이브러리 기반 도구입니다. Kernel/Host/Verifier의 권한을 대체하지 않습니다.

## 설치 및 실행

저장소 루트에서 실행합니다. GUI는 Tkinter가 포함된 Python 설치가 필요합니다.

```powershell
cd "$env:USERPROFILE\Downloads\base_harness"
python tools\harness-workbench\workbench.py --diagnose --harness-root .
python tools\harness-workbench\workbench.py --gui --harness-root .
```

저장소가 기본 Downloads 경로에 있다면 `tools\harness-workbench\run-workbench.bat`를 실행해도 됩니다. 다른 위치면 `BASE_HARNESS_ROOT` 환경변수를 지정하세요.

## 자주 쓰는 명령

```powershell
# 환경 진단 (TLS 확인 포함)
python tools\harness-workbench\workbench.py --diagnose --harness-root .

# 명령 미리 보기: 실행하지 않음
python tools\harness-workbench\workbench.py --preview --harness-root . --workspace . --goal-file goal.txt

# 실제 상태 읽기
python tools\harness-workbench\workbench.py --status --harness-root . --log-file .agy-run-harness-monitor.log

# JSON으로 한 번 출력
python tools\harness-workbench\workbench.py --status --json --harness-root . --log-file .agy-run-harness-monitor.log

# 계속 갱신되는 상태 화면 (Ctrl+C로 모니터만 종료)
python tools\harness-workbench\workbench.py --watch --harness-root . --log-file .agy-run-harness-monitor.log
```

`--start`는 명시적으로 지정한 Run 하나만 시작합니다. `--follow`를 함께 주면 Workbench가 자식 프로세스가 끝날 때까지 대기하며 PID·종료 코드·로그 경로를 출력합니다. 자동 재시도나 강제 종료는 하지 않습니다.

```powershell
python tools\harness-workbench\workbench.py --start --follow --harness-root . --workspace . --goal-file goal.txt --log-file run.jsonl
```

## 환경 경계

WSL Harness + WSL AGY, Windows Harness + Windows AGY 조합을 사용하세요. Workbench는 현재 OS와 AGY 실행 파일 경로가 다른 경우 경고합니다. 토큰·비밀번호는 읽거나 출력하지 않습니다. TLS 확인은 `oauth2.googleapis.com:443`에 연결을 점검할 뿐 인증 요청을 보내지 않습니다.

## 상태 해석

하네스 상태는 `Prepare → Explore → Execute → Verify`로 표시합니다. 로그가 없거나 phase를 해석할 수 없으면 `UNKNOWN`으로 둡니다. 종료됐거나 오래된 기록은 현재 실행으로 표시하지 않습니다. Model/Domain/서브 에이전트 수는 가능한 경우 Host status 기록에서 읽습니다.
