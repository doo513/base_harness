# 15 — Do Not Do

Do not add RAG, vector DB, memory graph, multi-agent swarm, planner hierarchy, automatic skill learning, or model router unless the active stage requires it.

Do not confuse:
```text
Memory != State
RAG != Resume
Observation != Fact
Evidence existence != Evidence sufficiency
Read-only verifier != Correct verifier
Deterministic oracle != Perfect oracle
Checkpoint file != Resume semantics
Mock sandbox != Production sandbox
```

Do not overclaim universal/best/solved/secure properties beyond the exact evidence scope. Do not silently rewrite failed tests or earlier stage evidence; use later corrections. Actor may propose, act, and request completion, but may not commit trusted facts, modify sealed oracle criteria, or set completion directly.
